# Project 2B - AI Micro-Tools Strategy

## Goal
Cumulative net income of 200,000,000 RMB.

## Chosen Path (Highest Expected Value)
Build a portfolio of AI-powered micro-tools / digital products starting from zero capital.

Reasons:
- High margins, scalable.
- Can start with free infrastructure (GitHub, free tiers).
- AI strengths align with creation speed.
- Ceiling higher than pure content or services for long-term scale.
- Existing projects on Vercel show continuity.

Alternatives considered and deprioritized for Phase 1:
- Pure novel writing (slower scale).
- High-capital models.
- Pure services (harder for pure automation).

## Phase 1 Plan (Next 2-4 weeks)
1. Identify 1-2 high-demand, low-competition niches (e.g. AI resume tailor, commit message generator, niche prompt packs).
2. Ship free artifacts (templates, prompts, simple generators) that buyers would screenshot.
3. Collect real feedback / "I would pay if" signals via public posts, communities.
4. If signals positive, package into paid digital product (Gumroad / similar) or thin web tool.
5. Only then integrate payments (requires user for account setup).

## Constraints
- 0 starting capital.
- Legal, compliant only.
- No fictional metrics.
- Reinvest success into distribution/product.
